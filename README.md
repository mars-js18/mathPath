# MathMaster - PWA de Progreso Matemático (Duolingo + Khan Academy)

Una Progressive Web App (PWA) moderna, colorida e interactiva diseñada para dar seguimiento paso a paso a tu aprendizaje matemático desde cero enfocado en **Ciencias de la Computación**.

## ✨ Características

- 🎯 **Temario depurado y ordenado:**
  1. **Aritmética:** Desde cero hasta sistemas numéricos computacionales (binario, octal, hexadecimal) sin sistemas antiguos.
  2. **Álgebra:** Lógica, conjuntos, polinomios, matrices, progresiones y números complejos.
  3. **Geometría y Trigonometría:** Ángulos, transformaciones 2D, funciones trigonométricas y forma polar de números complejos.
  4. **Geometría Analítica:** Coordenadas cartesianas, rectas, circunferencias, polares y paramétricas (depurado de cónicas mecánicas).
  5. **Cálculo Diferencial:** Límites, derivadas, aplicaciones de optimización y regla de L'Hôpital.
  6. **Cálculo Integral:** Sumas de Riemann, integrales inmediatas, métodos esenciales (partes y fracciones parciales) y ecuaciones diferenciales básicas.
  7. **Módulos Esenciales de Computación:** Álgebra Lineal aplicada (David C. Lay), Matemáticas Discretas (Kenneth H. Rosen), Probabilidad y Estadística (Jay L. Devore).

- 🎨 **Diseño Duolingo + Khan Academy:**
  - Colores vivos temáticos para cada bloque (Verde, Azul, Dorado, Púrpura, Rojo, Cyan, Rosa).
  - Gamificación: Contador de racha diaria (🔥), Puntos de Experiencia XP (⚡), Niveles progresivos (👑) y confeti al marcar lecciones.
  - Dos vistas intercambiables: **Temario Detallado** y **Camino Duolingo** (mapa de progreso en zigzag).
  - Notas y apuntes personales en cada tema individual (✏️ / 📝).
  - Buscador reactivo en tiempo real para encontrar cualquier teorema o fórmula al instante.
  - Modo Oscuro / Claro.

- 📱 **Tecnología PWA (Progressive Web App):**
  - Funciona 100% offline gracias a su Service Worker.
  - Instalable en Android, iOS, Windows y Mac con pantalla completa.
  - Guarda tu progreso automáticamente en `localStorage`.
  - Herramientas para **Exportar** e **Importar** tu progreso en formato JSON para que nunca pierdas tus avances.

## 🚀 Despliegue en GitHub Pages

1. Sube este repositorio a GitHub.
2. En GitHub ve a **Settings** > **Pages**.
3. En **Branch**, selecciona `main` y la carpeta `/ (root)`, luego haz clic en **Save**.
4. ¡Listo! Tu app estará disponible en línea con soporte HTTPS y lista para ser instalada en cualquier dispositivo.
